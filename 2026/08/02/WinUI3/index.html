4. 当我们在如下页面切换主题时，会有不同的响应事件

在上图的设置中，用户可以选择不同的主题。例如，用户可以选择红色框所选的浅色主题，系统强调色为深蓝色。用户也可以选择蓝色框和黄色框所选的深色主题，系统强调色分别为紫色和红色。需要注意的是，用户选择不同的主题是会有不同的响应事件。

  • 当用户在深色和浅色主题间进行切换时（例如从红色框的主题切换到蓝色框的主题），会先触发三次ColorValuesChanged事件，然后触发一次ActualThemeChanged事件
  • 当用户在同一主题间进行切换时（例如从蓝色框的主题切换到黄色框的主题），会触发一次ColorValuesChanged事件

从源程序文件得到最终可运行的程序需要经过以下三个阶段： 编译→链接→运行 编译：将源程序中的#include的头文件进行替换，把函数的声明都替换到源程序中 链接：对于上一步声明的函数，去找这些函数的位置，进行链接 运行：根据上一步找到的函数的位置，在运行时，动态地去执行这些函数 由此，对应Visual Studio的三处配置（项目属性） 编译：VC++→包含目录 或 C/C++→附加包含目录（指定编译阶段去哪找头文件） 链接：VC++→库目录 或 链接器→附加库目录（指定链接阶段去哪这些待链接文件） 运行：根据上一步找到的函数的位置，在运行时，动态地去执行这些函数（指定运行阶段动态运行哪些DLL文件） 对于VC++→包含目录 其中已经包含了许多目录，这些目录别的项目也有，在这个角度上VC++→包含目录是全局的，其他项目也生效。 此外，也可以在VC++→包含目录 添加新的目录，这个新添加的目录只对当前项目有效。 对于C/C++→附加包含目录，里面原来是空的，新添加目录只对当前项目有效。 编译：VC++→包含目录 或 C/C++→附加包含目录（指定编译阶段去哪找头文件） 链接：VC++→库目录 或 链接器→附加库目录（指定链接阶段去哪这些待链接文件） 运行：根据上一步找到的函数的位置，在运行时，动态地去执行这些函数（指定运行阶段动态运行哪些DLL文件） 当编译器的查找顺序通常是： 1.源文件所在目录 2.附加包含目录 3.包含目录 4.系统环境便令
