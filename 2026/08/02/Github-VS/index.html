将VS项目推送到一个含有readme文件的仓库

Created2026-08-02|Updated2026-08-02
|Post Views:

现git上有一个仓库，里面已经有了README文件

同时，我已经有了一个VS项目，里面已经有了代码，我想让其推送到该仓库进行团队协作，步骤如下：

  1. 创建Init仓库

  2. 创建Git仓库时，勾选“仅限本地”

  3. 管理远程存储库

  4. 输入名称和Git仓库的地址

  5. 之后在终端输入

  6. 之后再在终端输入

    之后VS项目就推送到仓库中可以进行团队协作了
